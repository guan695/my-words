# 拾词使用指南

[返回项目首页](https://github.com/guan695/my-words)

## 安装、启动与退出

从 [Releases](https://github.com/guan695/my-words/releases/latest) 下载 `MyWords-Windows-x64.zip`，解压后运行 `MyWords.exe`。保留同目录的所有文件。完整版带有运行环境；名称包含 `framework-dependent` 的精简版需要另装 .NET 8 Desktop Runtime x64。

拾词面向 Windows x64，目前没有安装器，也未做代码签名。请从本仓库的 Releases 下载，发布页同时提供 `SHA256SUMS.txt`。可在 PowerShell 中用 `Get-FileHash .\MyWords-Windows-x64.zip -Algorithm SHA256` 对照校验值。

- 关闭窗口或按 **Esc**：收起到 Windows 托盘，继续接收 Manggo 收藏。
- 左键点击托盘图标：打开单词库。
- 右键托盘图标：打开单词库、进入今日学习或退出程序。
- **Ctrl + L**：切到收藏输入框。
- `MyWords.exe --background`：启动后直接驻留托盘。

收录成功、重复收藏和 AI 整理完成的提示显示在窗口底部，不弹出托盘通知；发生错误时才弹出提醒。收起窗口也不会弹通知。

Windows 决定图标显示在任务栏还是隐藏图标区，你可以自行拖动图标。重复启动程序会唤醒已有窗口。

## 开机自动启动

在「设置 → 启动与托盘」中勾选「开机自动启动」，切换立即生效，不用再点「保存设置」。默认关闭；开启后，当前账户登录 Windows 时，拾词会自动启动并驻留托盘。取消勾选即可移除拾词的启动项。

移动程序文件夹后，请从新位置打开拾词，把该选项关闭再开启一次，更新启动位置。请保留程序文件夹中的全部文件。如果在 Windows 设置或任务管理器中另行禁用了拾词启动，也需要在那里重新允许启动。

本功能使用当前用户的 Windows Run 启动项，不需要管理员权限。Windows 可以延后运行启动项，因此不一定在登录瞬间出现图标。依据：[Microsoft 启动项说明](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。

## 收藏、计数与 AI 词卡

输入英文单词或短语，按 Enter 收藏。短语最多 8 个词，大小写和多余空白会统一处理，`run` 和 `running` 分别收录。

「收藏 5 次」表示首次收藏加上 4 次重复。这个数字记录主动收藏次数，不代表阅读中实际遇见的次数。重复收藏只累加计数，不覆盖词卡，也不自动再次调用 AI。

在「设置」里填写自己的 DeepSeek API Key、模型名称及整理提示词，并保存。新词可以自动生成词卡，已有词可以点击「AI 整理」。可以从这样的提示词开始：

> 我是英语初学者。只解释最常见的意思，给出一个生活场景中的简短英文例句和中文翻译，补充常用搭配。音标不确定时留空。

AI 失败时，单词和原词卡会保留。如果生成期间手动修改了词卡，程序会保留手动编辑。Manggo 词典已有的音标会优先保留，缺失时再交给 AI 补充。

## 每天如何选词

每天首次进入「今日学习」时，从自己的词库抽取最多 20 个不同的词；不足 20 个时使用全部单词。当日固定，重启不会重新抽取，当日后续新增的词从下一天开始参与抽选。

先尝试回忆，再显示答案，根据实际情况标记「忘记了 / 模糊 / 记住了」。忘记的、未学的和反复收藏的词有更高的抽选权重，每个词都有机会。这是加权抽选，还不是完整的间隔复习算法。

日期使用电脑的本地日期，仅用于当天词表与进度，不记录收藏时间。

## 接入 Manggo Pro

1. 在 Manggo「插件管理」中点击 **初始化插件环境 / Initialize Plugin Environment**，等待显示 **就绪 / Ready**。
2. 安装下载包中的 `MyWords.mplugin`，也可以从 Releases 单独下载该文件。
3. 在 Manggo 的生词本服务设置中添加「拾词」。安装插件后还需要添加服务。
4. 在拾词「设置 → 连接 Manggo Pro」中点击「复制连接口令」。
5. 把口令粘贴到 Manggo 的拾词服务配置并保存。
6. 保持拾词运行，划词翻译后选择收藏到拾词。

插件只连接本机 `http://127.0.0.1:17653/words`，不需要部署服务器。口令由每台电脑上的拾词生成，请勿公开粘贴到 Issue。

## 备份、迁移与更新

「设置」中的导出功能生成 JSON 词库备份，不包含 API Key。导入会补充未收录的词；已有单词和计数保持不变，不会合并重复词的计数。

词库默认位于 `%LOCALAPPDATA%\MyWords\words.json`，设置是同目录下的 `settings.json`。保存时保留上一版 `.bak`。文件损坏时程序会提示错误，不会自动清空词库。

迁移到其他电脑时，建议在旧电脑导出词库，在新电脑导入，并重新填写自己的 API Key、重新配对 Manggo。密钥受到 Windows 当前用户加密保护，直接复制设置文件不能保证在另一台电脑上解密。

更新前可先导出一份备份，再从托盘右键退出拾词，解压新版本并运行。词库在应用目录之外，正常更新不会替换词库。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| `Plugin runtime environment is not initialized.` | Manggo 的插件环境尚未初始化。进入「插件管理」完成初始化，等待 Ready；无需因此重装拾词插件。 |
| Manggo 无法连接拾词 | 确认拾词在运行，检查窗口底部是否提示端口被占用；退出占用 17653 的程序后重启拾词。 |
| 提示连接口令不正确 | 从当前电脑的拾词设置重新复制口令，粘贴到 Manggo 的拾词服务配置并保存。 |
| 提示需要安装 .NET | 下载自带运行环境的完整版，或为精简版安装 .NET 8 Desktop Runtime x64，注意不要只装 ASP.NET Runtime。 |
| AI 提示密钥无效、余额不足或模型不接受请求 | 检查自己的 DeepSeek Key、账户余额和模型名称。单词已保留，修正后可再次点击「AI 整理」。 |
| 关闭窗口后找不到程序 | 查看右下角隐藏图标区，点击拾词的 `w` 图标；也可以再次启动程序唤醒窗口。 |

仍有问题可以 [提交 Issue](https://github.com/guan695/my-words/issues/new/choose)。附上应用版本、Windows 版本、操作步骤和错误提示即可；不要上传密钥、连接口令或完整个人词库。
